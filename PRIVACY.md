# Privacy Policy

WatchMouse does not collect, store, share, process or otherwise use any user
data.

The app does not include any analytics, advertising, tracking or telemetry.

The in-app "Check for updates" feature, when explicitly triggered by the user,
queries the public GitHub Releases API for this project's latest release to
compare it with the installed version. This request contains no personal or
device data. All Bluetooth communication stays on-device and local.
